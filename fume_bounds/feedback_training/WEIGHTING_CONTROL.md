# NUS 负结果与一次训练正例率权重对照

> **2026-11-10 状态更新：暂停作为研究主线，新增真实训练仍为 0／6。** 下文保留已写好的历史控制方案和运行入口。理论核验表明：权重变更不能建立真实概率覆盖，也不能推出原 EU 收缩或实际 mAP 改进；下一步应按 [完整推导](../theory/20261110_evidence_bounds/DERIVATION.md) 核对固定教师、观测机制、有效集合及同机制的实际排序差值。暂停依据是研究判断，不把服务器访问状态当作理论缺口的解释。

## 已有结论

固定提交 [4c7f97f](https://github.com/XinchengSun/fume-bound-feedback/commit/4c7f97fa657f7e3240b64e10e932758426602b32) 的 12 组真实训练已完成。复核 1,620 次逐步记录、72 行验证记录、36 行测试终点和 504 项配对值，配对数值最大复算差为 0。这里独立重算归档，没有在当前环境重新运行服务器上的模型训练。机器可读复核见 [review_4c7f97f.json](review_4c7f97f.json)。

**当前 50:50 正负权重下的完整下界损失，在这份共同检查点和五轮预算下失败。** 固定第 5 轮，完整下界比均值监督低 0.09638568 个百分点，比原 FUME 续训低 0.06418139 个百分点，均为 0 胜 3 负。其 Brier、NLL、ECE 也全部差于均值监督。原始数值见 [final.csv](records/20261110_nus/final.csv)。

## 唯一新增干预

当前反馈采用

\[
R_{bal}=0.5\,\overline{\ell}_{+}+0.5\,\overline{\ell}_{-}.
\]

NUS 全配对的正例率为 0.1，当前风险给正例相对负例的权重放大为自然比例下的 9 倍。这是目标函数中的类别成本选择，不是实现错误，也不能仅凭均值上移就确认它导致了全部负结果。

只新增 train_prior 权重：

\[
\rho=\sum_c(n_c/n)^2,\qquad
R_{prior}=\rho\,\overline{\ell}_{+}+(1-\rho)\,\overline{\ell}_{-}.
\]

类别计数只来自训练标签，按已登记的均衡训练划分预期 rho=0.1；运行时从实际训练标签计算并记录，整次训练固定。沿用原批内全交叉配对，包括对角正对；因此本对照是匹配训练总体类别比例的权重变更，不把批内样本均值声称为精确自然总体风险。实际批内正例比例单独保存。

新增两个训练臂：FUME＋train_prior 后验均值、FUME＋train_prior 完整下界。各使用 110104、110105、110106 三个共同次序种子，5 轮、batch 300、lr=5e-5、反馈系数 1，仍为同一检查点、支持库、全部 8,000 个训练行和原 Adam 连续状态规则。每组 135 步，共 **6 组、810 次新增更新**。不新增调参搜索，不改变配对或丢弃样本。

## 历史对照复用

旧 balanced 两臂和原 FUME 作为分别注明来源的对照。新运行须登记旧协议哈希，验证输入特征、检查点、数据、支持索引、完整批次表和共同起点一致。旧结果仍属于原代码版本，不能伪装为由新代码重跑。新增代码的 balanced 默认路径须通过与原实现的损失和梯度兼容测试。

可复用旧的已登记特征缓存，但只接受原输入哈希及原发布提取入口的精确对应；不能改旧 feature_manifest 来冒充新提取。训练器会拒绝输入或参考协议不一致。

## 运行

使用已完成旧运行目录里的 prepared/features.pt 与 feature_manifest.json，沿用旧运行的 Python 环境和数值库版本；预检会拒绝版本不一致。在仓库根目录执行，NEW_OUTPUT 必须不存在：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=3 MKL_NUM_THREADS=3 \
python -u fume_bounds/feedback_training/run.py train \
  --features "$PREVIOUS_RUN/prepared/features.pt" \
  --previous-run "$PREVIOUS_RUN" \
  --feedback-weighting train_prior --arms predictive_mean full \
  --out "$NEW_OUTPUT"
```

也可以用 all 子命令重新提供 checkpoint 和 dataset；输入检查、提取、测试时序均保留。PREVIOUS_RUN 指有完整原始小型记录的旧运行目录，不需要公开权重或数据。Git 归档可作为旧记录对照，特征路径单独提供。

## 固定观察项

主终点仍为第 5 轮，第一比较为 train_prior full − train_prior predictive_mean。还报告两种权重下 full − mean 的差中差，以及新两臂分别相对旧原 FUME 的差值。差中差只描述这份配对设计，不构成总体因果或显著性声明。

原有双向和单向 mAP、Brier、NLL、ECE、端点、AU/EU 保留；新增正负条件 Brier、NLL 和平均预测概率、两种权重口径的事件损失。每轮首批记录反馈梯度与原 FUME 梯度范数的比例和夹角；其余批次对应字段留空，采样频率写入配置。诊断不改变实际梯度、反馈系数或训练选择。

权重改变也可能改变反馈梯度的整体强度。因此即使新方案改善，也不直接断言已经排除了梯度尺度因素；先用登记的范数诊断解释。旧记录缺失的子组指标不填造、不作伪配对。

## 停止规则与范围

1. 若 train_prior 的完整下界在三个配对次序上仍不能一致优于同权重均值监督，结束当前“直接把该下界加到训练损失”的设计，不继续通过延长轮次、改变系数或挑选测试结果挽救。
2. 只改善概率评分而没有检索收益时，按概率评分结果报告，不宣称检索方案成功。下界或 EU 数值变小本身也不算成功。
3. 即使三个次序均领先，仍需看实际差值大小，最多进入独立编码器起点验证；当前数据不支持总体显著性、跨数据集稳健性或逐对概率覆盖声明。
4. 本阶段不新增支持观测。学习后的模型读出变化不能被解释成已证明“新增证据减少认知不确定性”。

这一次控制有具体目标：区分当前失败是否对正负风险权重敏感。它不撤销已得到的负结果，也不改变独立认证仍缺数据和概率对象前提的状态。新增六组真实训练尚未在当前执行环境启动；已完成的代码验证及访问阻塞见 [weighting_control_validation.json](weighting_control_validation.json)。
