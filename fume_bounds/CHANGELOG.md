# 变更记录

## 2026-11-06 — v5：多标签类别证据替换 fuzzy 分支

- 新增独立 `fume_bounds/v5/`，训练入口 `train.py`，独立评测入口 `evaluate.py`；旧 vls_transfer 和 v3/v4 文件保持不变。
- 复用 FUME 双编码器、固定方形正交 W 和原对比目标；移除必要性、可信度 c、fuzzy 损失及二元图文 pair 证据头。
- 完整 multi-hot 类别监督；不对标签取 argmax、不归一化类别和。类别映射读取归一化前 h，检索仍使用单位 z。
- 保留“证据＋1”：每模态 K 个证据方向和一个共享证据预算，最终概率、BCE、逐标签 Beta 期望损失使用同一参数化。共享预算的表达限制已写入 METHOD.md。
- 同时实现类别 Mixup、噪声邻域、两路类别不确定性、全量无筛选检索评测、数据与代码哈希、完整 Adam/RNG 续训。
- v5 本次 CPU 测试 33 passed；另以原 INRIA 4096宽度/4层结构、122396674参数完成合成输入的一次真实 Adam 更新。不是旧版测试计数，也不是实际 INRIA 效果。
- 运行说明、逐分支公式、激活、复用边界和原始完整尺寸检查数值均见 v5 目录。没有执行 GPU/真实数据训练或声称性能提升。

## 2026-11-05 — VLS v2：补齐可信性评测与独立重载

- 保留匹配级 VLS 两项监督、原 FUME 损失和默认权重；没有新增逐标签分支、风险求界或回滚机制。
- 新增 `uncertainty.py`：TU、AU、互信息 EU、Dirichlet 微分熵、vacuity，统一使用 nats；支持严格输入和数值检查。
- 新增 `evaluate_vls.py`：训练后或已训练 checkpoint 独立评测；恢复 encoder、普通 Tensor W 和证据头，不用随机头冒充已训练模型。
- 保留全查询全候选余弦 mAP；新增固定种子的自然分布配对抽样，用于 Brier/NLL/ECE、错误检测和风险—覆盖评测。保存配对索引、预测和协议哈希。可信性配对抽样不影响 mAP 分母。
- OOD 仅使用用户明确提供的外部分布配对；未提供时记录 not_run，不把负配对或高斯噪声称为真实 OOD。
- 修正并列不确定性分数的 AURC 顺序偏差；退化单类 AUROC 返回 null；补齐配置、标签及未训练证据头保护。
- 新增公式映射、官方源码可用性核查及理论边界说明：官方页面有 Supplemental ZIP，但本次下载失败，未核验其代码内容；未发现可核验作者 GitHub，不等于断言未开源。
- 当前 VLS 子目录 CPU 测试 43 passed（14 旧例＋29 新例）；含训练—保存—独立重载—评测联动。未运行真实 INRIA/GPU，未声称性能提升。

## 2026-11-05 — VLS 完整跨模态迁移初版（未调参）

- 新增 `fume_bounds/vls_transfer/`：NeurIPS 2025 VLS 的 strong mixup（Beta(10,10)）、Gaussian noise vicinal（Beta(1,1)）和二类 Dirichlet 期望交叉熵。
- 以同一个混合系数分别混合图像／文本原始预提取特征，随后经原 FUME 双编码器计算图文匹配证据；保留 FUME 原模糊监督和对比损失，新增损失梯度实际传入两路编码器。
- 配对监督为多标签共享类别产生的二元相关性；所有原始训练样本保留，负配对来自无标签交集的候选。噪声、混合、clean 监督及权重均可配置，默认完整启用原 VLS 两项。
- 增加独立入口、无筛选全量 I→T/T→I mAP 评测、W 完整保存、固定轮次末尾测试及 14 项 CPU 测试（含模拟 FUME 命令行端到端检查）。
- 未完成真实 INRIA/GPU 实验；混合图文匹配标签的有效性需实验验证，不能把原分类论文的泛化定理直接用于跨模态任务。
