# NUS 认证停在 P0a

**决定：已有证据支持的独立认证实体为 0，实际认证对为 0。** 当前 FUME 项目的已登记 NUS 数据是同一个 10k 文件。原版编码器用 8,000 个训练行拟合，1,000 个验证行用于选择第 6 轮及比较超参数，1,000 个测试行作为双向查询和图库多次评测，历史结果已反馈到研究设计。原测试基准保留全部 1,000 个查询。本结论限定于已核验的数据来源，不排除另有尚未登记的数据。

历史概率头从训练数据抽取的 2,048 个不同加载器行组成 1,024 对，其中 103 个为正例。它们与 encoder_fit 的行重叠是 2,048；独立新增认证实体数量仍为零。本次没有重新拟合分子。按图像、文本分别对原特征逐行哈希，三个 split 内和三种跨 split 组合的完全相同向量计数均为 0。但 14 个 HDF5 字段及其属性中没有原始来源 ID、别名、裁剪谱系或标注者记录。哈希去重不能证明底层实体独立，更不能抵消历史使用。

冻结设计在历史支持对上的形状为 1,024×11，数值秩为 11。认证矩阵的秩未知。计算端已实查 NumPy、SciPy、Torch、mpmath；未检测到 CVXPY、Clarabel、python-flint 或 gmpy2 已安装。没有因数据阻塞安装求解器或更换特征。

| 验收 | 本次结论 |
|---|---|
| implementation_correct | 仅截距金标准通过，覆盖枚举、阈值、外包及独立高精度端点见 scalar_gold.json。高维投影、对偶证书及 verifier 未运行。 |
| model_conditional_validity | 若独立认证观测的正确条件似然成立、同族有限分子独立于认证数据，则真参数处的 split likelihood ratio 期望至多为 1，Markov 界给出 95% 参数集合保证，同一真参数事件蕴含同时投影保证。NUS 独立来源不满足，原始输入条件语义未解决。 |
| practical_informativeness | not_tested；无真实区间、宽度、排序认证率或运行效率结果。 |
| retrieval_gain | not_tested。 |

解除阻塞需要同总体、两模态均有来源块与历史去重记录、此前未参与拟合或研究选择的新实体；另一条路线是先明确总体和实体别名，在新的事前隔离协议下从头建立编码器及认证数据链。还需确定重复观测所对应的匹配语义。旧测试结果只保留描述用途。真实覆盖字段为 null。全后端、8 维模拟和检索训练均停止于门槛之前。

原始数据、权重、服务器私有路径不随源码发布。provenance.json 给出受控文件定位、代码及输入哈希；historical_averages.csv 与 historical_paired.csv 为逐字节导入，八批共享同一检查点和测试库。标量端点误差和墙钟记录在 scalar_gold.json，测试命令见模块 README。
