# 逐对匹配概率的条件对象

候选总体沿用 NUS deep 10 类配对协议，自然抽图文，Y 为两个来源行的单一存档类别相等。各划分每类样本均衡。在固定测试图库中全组合正例率为 0.1。X 表示原始图文内容，不含存档类别、显式来源 ID 或配对答案。若将 X 理解为确定的两条完整数据库记录，标签相等是确定事件，条件概率为 0 或 1。该数据没有针对固定 X 的独立语义判断，也未定义随机标注者人群，不能直接把存档类别事件等同于人群语义匹配倾向。

目标仍为 P*(Y=1|X=x)。有限 logistic 系数对原始内容的正确设定以及冻结特征的充分性均为 assumed_not_proven。若只能估计同一特征条件下的平均率，应报告 weaker_scope。本次没有估计新概率。推理特征为截距和 10 倍归一化两塔表示的逐维乘积，共 11 维，无基于认证数据的标准化。该设计和原标签版本均通过哈希登记。
